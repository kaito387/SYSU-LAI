# 《人工智能》理论课 Roadmap（90+ 目标）

## 0. 总主线

这门课的主线不是"很多 AI 名词"，而是：

1. **知识如何表示**：谓词逻辑、产生式、框架、知识图谱。
2. **表示后的知识如何推理**：自然演绎、子句集、归结反演；不确定知识用可信度、证据理论、模糊推理。
3. **无法直接推理时如何搜索**：状态空间、BFS/DFS、A/A*、博弈树与 alpha-beta 剪枝。
4. **大规模优化如何近似求解**：遗传算法、模拟退火。
5. **如何从样本中学习分类边界**：感知器、多层感知器、BP 误差反传。

90+ 的目标是：每个模块都能说清概念，但尤其要能手算归结、A*、alpha-beta、CF/D-S/模糊、GA/SA 设计、感知器/BP。

## 1. 知识表示：所有后续推理的语言基础

参考：`知识表示概述.ppt`

### 必掌握概念

- 知识：信息之间的关联结构；智能活动依赖知识。
- 知识特性：相对正确性、不确定性、可表示性、可利用性。
- 不确定性来源：随机性、模糊性、经验性、不完全性。
- 知识表示方法选择原则：充分表示领域知识；便于利用、组织、维护、理解和实现。

### 一阶谓词逻辑

- 命题：非真即假的陈述句。
- 谓词：`P(x1, x2, ..., xn)`，表示个体性质、状态或关系。
- 个体可以是常量、变量、函数；注意课件中也提到二阶谓词例子。
- 连接词：非、析取、合取、蕴含、等价。
- 量词：全称、存在；量词顺序会改变语义。
- 谓词公式：原子公式、复合公式、量词公式。
- 辖域、约束变元、自由变元。
- 谓词公式性质：解释、永真、永假、可满足、不可满足、等价、永真蕴含。
- 推理规则：P 规则、T 规则、CP 规则、假言推理、拒取式推理、反证法。

### 产生式表示

- 规则知识：`IF P THEN Q`，不确定规则为 `IF P THEN Q (置信度)`。
- 事实知识：三元组 `(对象, 属性, 值)` 或 `(关系, 对象1, 对象2)`；不确定事实加置信度成为四元组。
- 产生式系统：规则库 + 综合数据库 + 控制/推理机。
- 控制系统工作：匹配规则、冲突消解、执行规则、计算不确定性、检查终止。
- 产生式与逻辑蕴含区别：产生式可表示操作、变换、不精确匹配；蕴含式只表达精确逻辑关系。
- 典型例子：八数码的状态/规则/控制策略；动物识别系统。

### 框架与知识图谱

- 框架：描述对象属性的数据结构，由槽、侧面、槽值、侧面值组成。
- 框架特点：结构性、继承性、自然性。
- 知识图谱：实体、属性、关系构成的图；常用三元组表示。
- 知识图谱架构：数据层与模式层；构建方式有自顶向下、自底向上。

### 90+ 要求

- 能把自然语言改写成谓词公式。
- 能区分产生式、谓词逻辑、框架分别适合什么知识。
- 能解释为什么八数码既可看成产生式系统，也可看成状态空间搜索问题。

## 2. 确定性推理：归结法是大题核心

参考：`确定性推理方法（逻辑推理）.ppt`

### 推理分类

- 演绎推理：一般到个别。
- 归纳推理：个别到一般，分完全归纳和不完全归纳。
- 默认推理：知识不完全时默认某些条件成立，属于非单调推理。
- 确定性推理 vs 不确定性推理。
- 单调推理 vs 非单调推理。
- 启发式推理：用领域知识提高效率。

### 推理方向

- 正向推理：事实驱动，简单但目的性弱。
- 逆向推理：目标驱动，目的性强但初始目标选择可能盲目。
- 混合推理：先正后逆或先逆后正。
- 双向推理：正向与逆向同时推进，直到中间相遇。
- 冲突消解：按针对性、新鲜性、匹配度、条件个数排序。

### 子句集转换流程

必须背熟并会做：

1. 消去蕴含与等价。
2. 否定内移到谓词前。
3. 变量标准化。
4. 消去存在量词，即 Skolem 化。
5. 化为前束形。
6. 化为 Skolem 标准形。
7. 略去全称量词。
8. 消去合取词，得到子句。
9. 子句变量标准化。

关键定义：

- 文字：原子谓词公式或其否定。
- 子句：文字的析取。
- 空子句 NIL：永假，不可满足。
- 定理：谓词公式不可满足当且仅当其子句集不可满足。

### 归结原理

- 命题归结：两个子句含互补文字，消去互补文字并析取其余部分。
- 谓词归结：先合一，再归结。
- 最一般合一 mgu：使两个文字相同的最一般替换。
- 归结式是亲本子句的逻辑结论。
- 若从子句集归结出空子句，则子句集不可满足。

### 归结反演

证明 `F |= Q` 的流程：

1. 前提 `F` 表示为谓词公式。
2. 结论 `Q` 取否定 `not Q`。
3. 将 `{F, not Q}` 化为子句集。
4. 连续归结。
5. 推出 NIL，则证明 `Q` 成立。

求解问题时，把目标否定后与 `ANSWER` 析取，归结出 `ANSWER` 即得到答案。

### 90+ 要求

- 能完整写出自然演绎证明，如"小王喜欢 ds"。
- 能把公式化为子句集，不跳步。
- 能做公司录取 C、兄弟姐妹、老师是谁这类归结反演题。
- 易扣分点：Skolem 函数是否依赖外层全称变量；变量是否标准化；结论是否先否定。

## 3. 不确定性推理：CF、D-S、模糊推理三套账

参考：`不确定性推理方法(1).ppt`

### 基本问题

- 不确定性表示与量度。
- 不确定性匹配算法与阈值。
- 组合证据不确定性算法。
- 不确定性传递算法。
- 结论不确定性合成。

### C-F 可信度方法

- CF(H, E) 表示证据 E 对结论 H 的支持强度，范围 `[-1, 1]`。
- `CF > 0` 支持 H 为真；`CF < 0` 支持 H 为假；`CF = 0` 无关。
- 静态强度：规则本身 `CF(H, E)`。
- 动态强度：当前证据 `CF(E)`。
- 初始证据：真为 1，假为 -1，不确定时在两者之间。
- 合取证据：取 `min`。
- 析取证据：取 `max`。
- 传递：结论可信度由规则强度和证据强度共同决定，课件强调从不确定证据经不确定规则得到不确定结论。
- 多条规则支持同一结论时，需要做结论合成。

### D-S 证据理论

- 样本空间 D：变量所有互斥可能取值。
- D 的任意子集代表一个命题。
- 基本概率分配函数 `M(A)`：把每个子集映射到 `[0,1]`，且总和为 1，`M(empty)=0`。
- 注意 `M({红}) + M({黄}) + M({蓝})` 不一定等于 1，因为质量可分配给复合命题。
- 信任函数 `Bel(A)`：A 为真的总信任度。
- 似然函数 `Pl(A)`：A 不被反驳的上限。
- 正交和：Dempster 证据组合；若冲突系数导致不可组合，则证据矛盾。

### 模糊推理

- 模糊集合：元素属于集合的程度由隶属度 `[0,1]` 表示。
- 隶属函数：三角、梯形、正态等；可由统计、专家经验、排序、概念扩充确定。
- 模糊集合运算：包含、相等、交、并、补；还包括代数积、代数和、有界和、有界积。
- 模糊关系：用模糊矩阵表示两个论域元素的关联程度。
- 模糊推理：规则 `IF A THEN B` 对应模糊关系矩阵 `R`，输入模糊向量与 `R` 合成得到输出模糊向量。
- 清晰化：最大隶属度法、加权平均判决法、中位数法。

### 90+ 要求

- 能手算 CF 合取/析取、传递、合成。
- 能从给定 `M(A)` 算 `Bel`、`Pl`，并做简单证据组合。
- 能按"确定 R -> 合成 -> 清晰化"做模糊控制例题。

## 4. 状态空间搜索与 A*：算法题核心

参考：`状态空间搜索与A Star(1).ppt`

### 状态空间表示

- 问题求解两件事：问题表示 + 求解方法。
- 状态：描述系统状态的一组变量或数组。
- 操作：导致状态变化的函数或关系。
- 状态空间四元组：状态集合、操作算子集合、初始状态集合、目标状态/路径信息。
- 解：从初始状态到目标状态的有限操作序列。
- 典型例子：八数码、TSP、积木世界。

### 搜索策略

- 正向搜索、逆向搜索、双向搜索。
- 盲目搜索：无领域信息，按固定规则扩展。
- 启发式搜索：利用领域知识重排 OPEN 表，优先扩展有希望节点。

### 盲目搜索

- 回溯策略：
  - PS：当前路径。
  - NPS：待搜索状态。
  - NSS：不可解状态。
- BFS：
  - 逐层扩展。
  - OPEN 先进先出。
  - 有解则能找到，但代价高。
- DFS：
  - 扩展最新产生节点。
  - OPEN 后进先出。
  - 常需深度限制。
  - 不保证最短路径。

### A 与 A*

- 估价函数：`f(n) = g(n) + h(n)`。
- `g(n)`：初始节点到 n 的实际代价。
- `h(n)`：n 到目标的估计代价。
- A 搜索：按 `f(n)` 从小到大选择 OPEN 中节点扩展。
- 八数码常用启发：
  - 不在位数。
  - 曼哈顿距离。
  - 逆转数相关函数。
- A*：满足最优性条件的 A 搜索。
- 可采纳性：能保证找到最短路径。
- 单调性：若 `h(ni) - h(nj) <= cost(ni, nj)` 且目标 `h=0`，则启发函数单调。
- 信息性：若 `h1(n) <= h2(n)`，则 `h2` 信息性更强，通常扩展节点更少，但计算代价可能更高。

### 90+ 要求

- 能给八数码画搜索树，标注 `g/h/f` 和 OPEN/CLOSED。
- 能解释 A 与 A* 的区别：A 是按估价函数搜，A* 还要求启发函数不高估/满足可采纳条件以保证最优。
- 能判断 BFS/DFS/A* 的完备性和最优性差异。

## 5. 博弈搜索：Minimax 与 alpha-beta

参考：`博弈与搜索 2022.ppt`

### 博弈基本概念

- 零和对策：一方收益等于另一方损失，如田忌赛马。
- 非零和对策：如囚犯困境。
- 博弈程序需要：
  - 好的走步生成过程。
  - 好的静态估计函数。

### 极小极大搜索

- MAX：程序方，追求评价值最大。
- MIN：对手方，追求评价值最小。
- 静态估计函数 `f(p)`：
  - 有利 MAX 为正。
  - 有利 MIN 为负。
  - 均衡为 0。
- Minimax 思想：
  - MAX 层取子节点最大值。
  - MIN 层取子节点最小值。
  - 从端节点向上倒推。
- 三阶段：生成规定深度博弈树；端节点估值并倒推；按根节点倒推值选择走步。

### alpha-beta 剪枝

- alpha：MAX 层当前可保证的下界，永不下降。
- beta：MIN 层当前可保证的上界，永不上升。
- 一旦 `alpha >= beta`，可剪枝。
- alpha 剪枝：某 MIN 节点的 beta 小于等于其任一 MAX 先辈的 alpha，则剪掉该 MIN 节点以下剩余分支。
- beta 剪枝：某 MAX 节点的 alpha 大于等于其任一 MIN 先辈的 beta，则剪掉该 MAX 节点以下剩余分支。

### 90+ 要求

- 能对给定博弈树自底向上写出每个内部节点值。
- 能标注 alpha、beta 更新和剪枝位置。
- 能说明 alpha-beta 不改变最终 minimax 结果，只减少搜索。

## 6. 智能优化：遗传算法与模拟退火

参考：`遗传算法.ppt`、`遗传算法应用.ppt`、`模拟退火算法.ppt`

### 遗传算法 GA

- GA 是基于自然选择和遗传机制的随机搜索算法，适合复杂、非线性优化。
- 核心操作：选择、交叉、变异。
- 基本映射：
  - 个体 = 解。
  - 染色体 = 解的编码。
  - 基因 = 编码分量。
  - 适应度 = 评价函数值。
  - 群体 = 多个候选解。
- 编码：
  - 二进制编码：易实现，但相邻整数可能 Hamming 距离大。
  - Gray 编码：缓解相邻编码跳变。
  - 实数编码：直接在表现型上操作。
  - TSP 常用排列编码、随机键编码。
- 群体设定：
  - 随机初始种群。
  - 随机产生后选优。
  - 利用问题知识初始化。
- 适应度函数：
  - 最大化可直接映射。
  - 最小化需转为非负最大化形式。
  - 尺度变换用于处理过早收敛、停滞、欺骗问题。
- 选择：
  - 适应度比例/轮盘赌。
  - 排序选择。
  - 锦标赛选择。
  - 最佳个体保存。
- 交叉：
  - 一点交叉、二点交叉。
  - TSP 排列编码要用 PMX、OX、CX、位置/顺序/子路径交换等避免非法染色体。
- 变异：
  - 位点变异。
  - 逆转、插入、互换、移动。
  - TSP 常用 swap mutation、inversion mutation。
- 一般流程：初始化 -> 计算适应度 -> 判断终止 -> 选择 -> 交叉 -> 变异 -> 形成新群体 -> 循环。

### 模拟退火 SA

- SA 模拟物理退火：高温时更容易接受劣解，低温时趋向局部搜索。
- 本质：通过温度控制接受劣解概率，劣向转移是跳出局部极小的核心机制。
- 三函数两准则：
  - 状态产生函数。
  - 状态接受函数。
  - 温度更新函数。
  - 内循环终止准则。
  - 外循环终止准则。
- 常用接受函数：`min[1, exp(-DeltaC/t)]`。
- 初温越大，获得高质量解概率越大，但计算时间增加。
- 背包问题：0-1 编码；状态产生可用翻位操作。
- TSP：排列编码；状态产生可交换两个城市或翻转片段。

### 90+ 要求

- 能为一个优化问题写出 GA 的编码、适应度、选择、交叉、变异、终止条件。
- 能解释为什么 TSP 不能随便用普通二进制交叉。
- 能为背包/TSP 写出 SA 的状态表示、邻域生成、接受概率、降温与终止。

## 7. 前馈神经网络：感知器到 BP

参考：`第3章 (感知器）.ppt`、`第3章 (BP算法).ppt`

### 单层感知器

- 单层感知器本质上就是 M-P 神经元模型。
- 输入层只引入信息，输出层有处理能力。
- 净输入是加权和，输出通常用符号函数。
- 二维输入时，判别边界是直线；三维是平面；n 维是超平面。
- 能实现逻辑与、逻辑或。
- 不能实现异或，因为异或线性不可分。

### 感知器学习规则

- 有导师学习。
- 训练步骤：
  1. 权值初始化为小的非零随机数。
  2. 输入样本对 `{Xp, dp}`。
  3. 计算输出 `ojp(t)`。
  4. 调整权值：`wij(t+1) = wij(t) + eta * (dpj - opj) * xip`。
  5. 循环直至误差收敛或达到迭代上限。

### BP 算法（多层感知器误差反传）

- 多层感知器解决非线性问题（如异或）。
- 激活函数：sigmoid（连续可导）、ReLU 等。
- 前向传播：逐层计算净输入 -> 激活 -> 输出。
- 误差反传：从输出层反向计算各层误差。
  - 输出层误差：`δo = (d - o) * o * (1 - o)`。
  - 隐藏层误差：`δh = oh * (1 - oh) * Σ(δo * who)`。
  - 权值更新：`Δw = η * δ * o_in`。
- 链式法则求梯度是 BP 的数学基础。
- 损失函数常用 MSE 或交叉熵。

### 90+ 要求

- 能手算一轮前向传播加反向传播更新所有权重（保留 4 位小数）。
- 能解释为什么单层感知器不能解决异或，多层可以。
- 能区分感知器学习规则与 BP 算法的适用场景。
- 能解释 Sigmoid 和 ReLU 的导数形式及优缺点。

## 8. 概率图模型与贝叶斯网络

参考：`人工智能第九讲 概率图模型 正式版.pptx`、`ch5 不确定知识表示和推理-PDF新版(1).pdf`

### 概率基础概念

- 频率学派 vs 贝叶斯学派：前者重频次，后者重主观置信度。
- 条件概率：`Pr(B|A) = Pr(A,B) / Pr(A)`。
- 贝叶斯定理：`Pr(Y|X) = Pr(X|Y) * Pr(Y) / Pr(X)`。
- 后验 ∝ 先验 × 似然。
- 链式法则、全概率公式（加法法则）。
- 独立：`Pr(B|A) = Pr(B)`。
- 条件独立：`Pr(B|A,C) = Pr(B|A)`，即已知 A 后 C 不再提供关于 B 的信息。
- 独立性可大幅简化联合概率计算。

### 贝叶斯网络定义

- 有向无环图 DAG：节点 = 变量，边 = 依赖关系。
- 每个节点附条件概率表 CPT。
- 联合分布 = 局部条件概率乘积：`P(X) = Π P(Xi | Parents(Xi))`。
- 可将参数量从指数级别降到接近线性。

### D-分离与条件独立性判断（考试核心）

三种基本结构：

1. **顺连** `A -> C -> B`：给定 C，A 与 B 条件独立。
2. **分连** `A <- C -> B`：给定 C，A 与 B 条件独立。
3. **汇连** `A -> C <- B`（v-structure / collider）：
   - 不给定 C 时，A 与 B 独立。
   - **给定 C 或其子代后，A 与 B 变为依赖**（这是最特殊的，也是常考点）。

D-分离判断准则：若 A 与 B 之间的所有路径都被 blocked，则条件独立。路径被 blocked 当且仅当路径上存在：

- 顺连或分连结构且中间节点被给定，或
- 汇连结构且中间节点及其所有子代都未被给定。

### 朴素贝叶斯分类器

- 假设所有特征条件独立于类别标签。
- 基础公式：`P(y | x) ∝ P(y) * Π P(xi | y)`。
- 预测时选择最大后验概率的类别。
- 零概率问题用 Laplace 平滑解决。

### 贝叶斯网络参数学习

- 盘式记法（plate notation）表示重复结构。
- 参数估计：MLE 或贝叶斯估计。

### 90+ 要求

- 能对 10+ 种给定证据组合判断条件独立性（作业 2 的 1.3 题）。
- 能手算朴素贝叶斯分类（含 Laplace 平滑）。
- 能根据贝叶斯网络算条件概率、联合概率、边缘概率。
- 能构建满足指定独立条件的贝叶斯网络（作业 2 的 1.4 题）。

## 9. 决策树与聚类

参考：`人工智能 第十三讲 正式版(1).pptx`、`人工智能第十一讲 正式版.pptx`

### 决策树基本概念

- 内部节点：属性测试。
- 分支：测试结果。
- 叶子：分类结果。
- 学习过程：选择划分属性 -> 递归划分。
- 预测过程：从根沿测试路径到叶子。
- 终止条件：节点全同类 / 无剩余属性 / 无样本。

### 决策树核心算法

- CLS：基础算法，未规定属性选择策略。
- **ID3**（考试重点）：
  - 熵：`H(X) = -Σ p(x) * log2(p(x))`。
  - 条件熵：`H(Y|X) = Σ p(x) * H(Y|X=x)`。
  - 信息增益：`IG = H(Y) - H(Y|X)`，选增益最大者作为划分属性。
  - 注意信息增益倾向于选择取值多的属性。
- **C4.5**：用增益率替代信息增益，克服偏向多值属性问题。
  - 增益率 = 信息增益 / 属性固有值（分裂信息）。
- **CART**：用 Gini 指数，`Gini(D) = 1 - Σ(pk)^2`，选基尼指数最小的属性。

### 聚类分析

- K-means：
  - 流程：选 K 个质心 -> 分配数据点 -> 更新质心 -> 迭代。
  - 复杂度：O(n × K × I × d)。
  - SSE 评估；肘部法则选 K。
  - K-means++：改进初始质心选择，使初始点尽量分散。
  - 局限：不同大小/密度/非球形簇表现差。
- DBSCAN：
  - 基于密度：核心点、边界点、噪声点。
  - 两个参数 Eps 和 MinPts。
  - 擅长任意形状簇、抗噪声；不擅长密度差异大或高维数据。
  - 时间复杂度实际为 O(n²)（虽有早期论文称 O(n log n)）。
- 距离度量：欧氏距离、曼哈顿距离、余弦相似度。
- 簇评估指标：外部指标（熵）、内部指标（SSE、凝聚度/分离度）、相对指标。

### 90+ 要求

- 能手算 ID3：计算熵、条件熵、信息增益，完整画决策树。
- 能手算一次 K-means 迭代（分组 + 更新中心）。
- 能解释 ID3/C4.5/CART 的划分准则差异。
- 能比较 K-means 和 DBSCAN 的适用场景。

## 10. 深度学习：从 Word2Vec 到 Transformer

参考：`深度学习2.pptx`

### 词嵌入 (Word Embedding)

- One-hot 编码的缺点是向量正交，无法表达语义相似性。
- 分布语义学："由上下文定义词义"。
- Word2Vec：CBOW（上下文预测中心词）、Skip-gram（中心词预测上下文）。
- 共现矩阵 + SVD 降维也属于词嵌入方法。
- GloVe：基于全局词共现矩阵的对数双线性模型。
- 词向量的类比性质：`king - man + woman ≈ queen`。

### Seq2Seq 与注意力

- Seq2Seq = Encoder + Decoder，用于机器翻译等序列转换任务。
- 瓶颈：编码器将所有信息压缩为一个固定长度向量。
- 注意力机制：Decoder 每一步直接看 Encoder 所有隐藏状态，取加权和。
- 注意力的通用定义：给定一组 value 向量和一个 query 向量，按 query 与 key 的匹配度对 value 做加权求和。

### Transformer

- 完全基于注意力，无需 RNN。
- 设计动机：
  1. 降低每层计算复杂度。
  2. 最小化任意两词之间的路径长度（O(1) vs RNN 的 O(n)）。
  3. 最大化可并行化计算。
- 自注意力公式：`Attention(Q,K,V) = softmax(QK^T / sqrt(dk)) * V`。
- 多头注意力：多组 Q/K/V 并行计算后拼接，关注不同子空间。
- 位置编码：正弦编码或可学习嵌入，弥补无顺序信息的缺陷。
- 三个训练技巧：
  1. 残差连接：加原始输入，使得深层网络容易训练，避免梯度消失。
  2. 层归一化：对每个样本的特征维度归一化，稳定训练。
  3. 缩放点积：除以 `sqrt(dk)`，防止点积过大导致 softmax 梯度消失。
- 解码器额外使用掩码自注意力，防止看到未来 token。
- Scaling Law：模型大小、数据量、计算量增大时，性能呈幂律上升。

### LSTM（了解）

- 相比普通 RNN，LSTM 通过遗忘门、输入门、输出门和 Cell State 实现信息的长距离线性传递。
- Cell State 上的梯度是加法而非乘法，从根本上缓解了梯度消失问题。

### 90+ 要求

- 能解释注意力机制的计算过程和为什么要引入注意力。
- 能解释 Transformer 自注意力为什么比 RNN 好（并行、长距离依赖、路径长度）。
- 能解释残差连接和层归一化的作用及工作原理。
- 能解释 LSTM 为什么能缓解梯度消失。
- 能解释 Word2Vec 的 CBOW 和 Skip-gram 两种训练方式。

## 11. 强化学习

参考：`强化学习入门3小时张伟楠.pdf`

### 基本概念

- 强化学习定义：通过与环境交互，以试错方式学习，最大化累计奖励。
- MDP（马尔可夫决策过程）：(S, A, P, R, γ)。
  - S：状态集。
  - A：动作集。
  - P：状态转移概率矩阵。
  - R：奖励函数。
  - γ：折扣因子，接近 1 则看重长远回报。
- 马尔可夫性质："给定当前状态，未来与历史独立"。
- 回报（Return）：`G_t = R_{t+1} + γ*R_{t+2} + γ^2*R_{t+3} + ...`。
- V 值函数：`V(s)`，从状态 s 出发的期望回报。
- Q 值函数：`Q(s,a)`，从状态 s 出发、执行动作 a 的期望回报。
- Bellman 方程：`V(s) = Σ P(s'|s,a) * [R + γ*V(s')]`。

### 求解方法

- 动态规划（已知 MDP 模型）：策略迭代、价值迭代。
- 无模型方法（不知道 MDP 模型）：
  - 蒙特卡洛方法：完整采样一条轨迹后更新。
  - 时序差分 TD：每步都更新。

### Q-learning vs SARSA

|          | Q-learning (off-policy) | SARSA (on-policy)          |
|----------|------------------------|----------------------------|
| 更新公式 | `Q(s,a) += α[r + γ*max_a' Q(s',a') - Q(s,a)]` | `Q(s,a) += α[r + γ*Q(s',a') - Q(s,a)]` |
| 下一动作 | 取 max（贪婪，假设后续最优） | 实际执行的动作               |
| 特点     | 更激进，学习最优策略        | 更保守，考虑探索的影响        |

### 深度强化学习

- DQN：用神经网络近似 Q 函数。
- 策略梯度：直接对策略参数求梯度，`θ += α * ∇log π(a|s) * G`。
- Actor-Critic：同时学习策略（Actor）和价值函数（Critic）。

### 90+ 要求

- 能根据 MDP 图计算给定轨迹的回报和状态的 V 值。
- 能写出 Q-learning 和 SARSA 的更新公式并说明区别。
- 能解释 MDP 五元组和折扣因子的作用。
