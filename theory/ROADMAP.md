# 《人工智能》期末 90+ Roadmap

## 0. 总体主线

这门课不是一堆孤立名词，而是一条从“符号智能”到“统计学习/大模型智能体”的主线：

1. **知识表示**：把人类知识变成机器可处理的形式。
2. **逻辑推理**：用确定性规则做证明和求解，核心是子句集与归结。
3. **不确定推理**：现实证据不完全时，用概率、可信度、证据理论、模糊逻辑推断。
4. **搜索与博弈**：无法直接推出答案时，在状态空间/博弈树里找解。
5. **智能优化**：搜索空间太大时，用 GA、SA 这类近似优化算法。
6. **机器学习**：从数据中学习函数，核心是模型、损失、优化。
7. **深度学习与 Transformer**：用多层网络学习复杂表示，从 BP 到 CNN/RNN/LSTM/Attention/Transformer。
8. **强化学习与智能体**：智能体在环境中通过奖励学习策略，现代 AI Agent 把感知、规划、工具、记忆结合起来。

按 2021 B 卷和作业看，真正高分点集中在：**贝叶斯网络/朴素贝叶斯、归结、A*/alpha-beta、GA/SA、BP、CNN、强化学习**。

## 2. 知识表示

参考：

- `知识表示概述.ppt`
- `第一次理论作业.pdf`

### 必会概念

- 知识：信息之间的关联结构；智能活动依赖知识。
- 知识特性：相对正确性、不确定性、可表示性、可利用性。
- 不确定性来源：随机性、模糊性、经验性、不完全性。
- 知识表示原则：充分表示领域知识；便于利用、组织、维护、理解和实现。

### 一阶谓词逻辑

- 命题：非真即假的陈述句。
- 谓词：`P(x1, x2, ..., xn)`，表示个体性质、状态或关系。
- 个体：常量、变量、函数。
- 连接词：非、析取、合取、蕴含、等价。
- 量词：全称、存在；量词顺序改变语义。
- 谓词公式：原子公式、复合公式、量词公式。
- 辖域、约束变元、自由变元。
- 性质：解释、永真、永假、可满足、不可满足、等价、永真蕴含。
- 推理规则：P 规则、T 规则、CP 规则、假言推理、拒取式推理、反证法。

### 产生式、框架、知识图谱

- 产生式：`IF P THEN Q`，可带置信度。
- 产生式系统：规则库 + 综合数据库 + 控制/推理机。
- 冲突消解：针对性、新鲜性、匹配度、条件个数。
- 框架：框架名、槽、侧面、槽值、侧面值；特点是结构性、继承性、自然性。
- 知识图谱：实体、关系、属性构成的图，常用三元组表示。

### 90+ 检查

- 能用谓词逻辑表示 Hanoi、亲属关系、刑侦知识。
- 能解释产生式和谓词蕴含的区别。
- 能说明八数码既可看作产生式系统，也可看作状态空间搜索。

## 3. 确定性推理与归结

参考：

- `确定性推理方法（逻辑推理）.ppt`
- `归结-搜索理论课作业.docx`
- `归结-搜索理论课作业答案.docx`
- `第一次理论作业.pdf`
- `21年人工智能B卷.pdf`

### 推理分类

- 演绎推理：一般到个别。
- 归纳推理：个别到一般。
- 默认推理：知识不完全时默认某些条件成立，属于非单调推理。
- 确定性推理 vs 不确定性推理。
- 单调推理 vs 非单调推理。
- 启发式推理：用领域知识提高效率。

### 推理方向

- 正向推理：事实驱动，简单但目的性弱。
- 逆向推理：目标驱动，目的性强但初始目标可能盲目。
- 混合推理：先正后逆或先逆后正。
- 双向推理：正反同时推进，直到中间相遇。

### 子句集转换

必须会完整写步骤：

1. 消去蕴含与等价。
2. 否定内移。
3. 变量标准化。
4. Skolem 化，消去存在量词。
5. 化为前束形。
6. 化为 Skolem 标准形。
7. 略去全称量词。
8. 消去合取词，提取子句。
9. 子句变量标准化。

关键定义：

- 文字：原子谓词公式或其否定。
- 子句：文字的析取。
- 空子句 NIL：永假，不可满足。
- 不可满足性：归结证明的核心。

### 归结反演

证明 `KB |= f`：

1. 把 KB 化为子句集。
2. 把结论 `f` 否定后加入子句集。
3. 对子句进行合一和归结。
4. 推出空子句 NIL，则证明成功。

### 支持集与祖先过滤

- 支持集策略：优先用“结论否定相关子句”参与归结，减少盲目归结。
- 祖先过滤：归结的两个子句至少一个是初始子句，或一个是另一个的祖先。

### 常考题型

- 自然语言转谓词公式。
- 合一算法，求最一般合一 mgu。
- 公式转子句集。
- 用归结证明结论。
- 用归结求答案，如“John 可能偷什么”。

### 90+ 检查

- Skolem 函数是否依赖外层全称变量。
- 是否先否定结论再加入 KB。
- 每一步归结是否写清亲本子句与替换。

## 4. 不确定性推理

参考：

- `不确定性推理方法(1).ppt`
- `ch5 不确定知识表示和推理-PDF新版(1).pdf`
- `世界上最有用的数学思维之一——贝叶斯定理大白话讲解(1).pdf`

### C-F 可信度方法

- `CF(H, E) in [-1, 1]`。
- `CF > 0` 支持 H；`CF < 0` 反对 H；`CF = 0` 无关。
- 静态强度：规则本身的可信度。
- 动态强度：证据当前可信度。
- 合取证据：取 `min`。
- 析取证据：取 `max`。
- 多条规则支持同一结论时需要合成。

### D-S 证据理论

- 样本空间 D：互斥完备的可能取值集合。
- 基本概率分配 `M(A)`：质量可分配给单元素或复合子集。
- 信任函数 `Bel(A)`：对 A 为真的下界信任。
- 似然函数 `Pl(A)`：A 不被反驳的上界。
- Dempster 正交和：组合不同证据；冲突太大可能不可组合。

### 模糊推理

- 模糊集合：用隶属度 `[0,1]` 表示“属于”的程度。
- 隶属函数：三角、梯形、正态等。
- 运算：交、并、补、代数积、代数和、有界和、有界积。
- 模糊关系：用矩阵表示输入论域与输出论域的模糊关系。
- 推理：输入模糊向量与规则关系矩阵合成。
- 清晰化：最大隶属度法、加权平均法、中位数法。

### 90+ 检查

- 会算 CF 组合、传递、合成。
- 会从 `M(A)` 算 `Bel(A)` 和 `Pl(A)`。
- 会做模糊控制题：确定关系矩阵 -> 合成 -> 清晰化。

## 5. 状态空间搜索与 A*

参考：

- `状态空间搜索与A Star(1).ppt`
- `人工智能第七讲 搜索技术 II 正式版.pptx`
- `第二次理论作业.pdf`
- `归结-搜索理论课作业答案.docx`

### 状态空间表示

- 状态：描述系统的一组变量或数组。
- 操作：导致状态变化的函数或关系。
- 状态空间四元组：状态集合、操作算子集合、初始状态集合、目标状态/路径描述。
- 解：从初始状态到目标状态的有限操作序列。

### 盲目搜索

- 回溯：PS、NPS、NSS。
- BFS：逐层扩展，OPEN 先进先出，有解则能找到，通常可得最短步数。
- DFS：扩展最新节点，OPEN 后进先出，需深度限制，不保证最短。

### A 与 A*

- `f(n) = g(n) + h(n)`。
- `g(n)`：起点到 n 的实际代价。
- `h(n)`：n 到目标的估计代价。
- A 搜索：按 `f` 最小扩展。
- A*：当启发函数可采纳时保证最优。
- 可采纳：`h(n) <= h*(n)`，不高估真实最短剩余代价。
- 一致/单调：`h(ni) - h(nj) <= cost(ni, nj)`，目标 `h=0`。
- 信息性：在都可采纳时，`h2 >= h1` 通常搜索更少节点。

### 常考例题

- 八数码：不在位数、曼哈顿距离。
- 图最短路：给边权和启发值，写 OPEN/CLOSED。
- 农夫狼羊白菜：BFS 最短路径；自定义可采纳启发函数并证明一致性。

### 90+ 检查

- 每次扩展后写清 OPEN/CLOSED。
- `f/g/h` 标注不要混。
- 遇到重复状态要说明环检测或路径更新策略。

## 6. 博弈搜索与 alpha-beta

参考：

- `博弈与搜索 2022.ppt`
- `人工智能第七讲 搜索技术 II 正式版.pptx`
- `第二次理论作业.pdf`
- `21年人工智能B卷.pdf`

### Minimax

- MAX：程序方，取最大值。
- MIN：对手方，取最小值。
- 静态估计函数：
  - 有利 MAX 为正。
  - 有利 MIN 为负。
  - 均衡为 0。
- 从端节点向根节点倒推。

### alpha-beta 剪枝

- alpha：MAX 当前下界，永不下降。
- beta：MIN 当前上界，永不上升。
- 若 `alpha >= beta`，剩余分支不可能影响最优决策，可剪枝。
- alpha 剪枝：MIN 节点 beta 小于等于 MAX 先辈 alpha。
- beta 剪枝：MAX 节点 alpha 大于等于 MIN 先辈 beta。

### 循环博弈

作业中出现四格游戏：

- 标准 minimax 若不检测重复状态，会陷入无限递归。
- 修正：记录当前路径已访问状态；遇到环可当作平局/估值 0。

### 90+ 检查

- 按题目指定“从左到右”生成节点。
- 在树上标出剪枝位置和最优路径。
- 说明 alpha-beta 不改变 minimax 结果，只减少搜索。

## 7. 贝叶斯网络、朴素贝叶斯与概率图模型

参考：

- `人工智能第九讲 概率图模型 正式版.pptx`
- `世界上最有用的数学思维之一——贝叶斯定理大白话讲解(1).pdf`
- `第二次理论作业.pdf`
- `21年人工智能B卷.pdf`

### 概率基础

- 条件概率：`P(A|B)=P(A,B)/P(B)`。
- 贝叶斯公式：`P(Y|X)=P(X|Y)P(Y)/P(X)`。
- 联合概率、边缘概率、全概率公式。
- 独立与条件独立。

### 贝叶斯网络

- 有向无环图 DAG + 每个节点的条件概率表 CPT。
- 节点表示随机变量，边表示局部概率依赖。
- 联合概率分解：
  `P(X1,...,Xn)=prod_i P(Xi | Parents(Xi))`
- 参数量压缩：利用条件独立，避免直接列完整联合分布。

### 条件独立与 D-分离

必须掌握三种结构：

- 链式：`A -> C -> B`，给定 C 后 A 与 B 独立。
- 分叉：`C -> A`、`C -> B`，给定 C 后 A 与 B 独立。
- 碰撞/V 结构：`A -> C <- B`，未给定 C 时 A 与 B 独立；给定 C 或 C 的后代后，A 与 B 可能相关。

第二次作业的 11 个判断题就是这个考点的训练集。2021 B 卷判断题也考这个。

### 朴素贝叶斯

- 假设：给定类别 y 后，各特征条件独立。
- 分类：
  `argmax_y P(y) prod_i P(x_i | y)`
- 若出现零概率，要考虑 Laplace 平滑。
- 2021 B 卷给二值特征表，要求预测新样本类别。

### 贝叶斯网络计算

常见题型：

- 从数据表估计 CPT。
- 根据网络结构分解联合概率。
- 求边缘概率，如 `P(B=T)`。
- 求条件概率，如 `P(y=T | A1=F, A3=F)`。

### 90+ 检查

- 会画出 active/inactive path。
- 能根据 CPT 表算联合概率，再用归一化求条件概率。
- 朴素贝叶斯计算时，先验和每个条件概率都要写清。

## 8. 机器学习总论

参考：

- `人工智能 第十讲 正式版机器学习导论.pptx`

### 核心框架

- 机器学习：从数据中寻找函数映射关系。
- 三大任务：回归、分类、生成。
- 三步：
  1. 定义候选函数集合，即模型。
  2. 定义衡量好坏的损失。
  3. 通过优化找到损失较小的函数。
- 泛化与过拟合：模型在训练集好，不代表测试集好；需要正则化。

### 四大范式

- 监督学习：有标签，做分类/回归。
- 无监督学习：无标签，如聚类。
- 半监督学习：少量标注 + 大量未标注。
- 强化学习：智能体与环境交互，以最大化累计奖励为目标。

### 90+ 检查

- 能用“模型、损失、优化”解释任何 ML 方法。
- 能区分监督/无监督/半监督/强化学习的输入输出和典型任务。

## 9. 决策树

参考：

- `人工智能 第十三讲 正式版(1).pptx`
- `第三次理论作业.pdf`
- `机器学习-深度学习理论课作业.docx`

### 基本思想

- 决策树用内部节点测试属性，叶节点给类别。
- 自顶向下递归构建。
- 每一步选择“最能划分类别”的属性。

### ID3

- ID3 使用信息增益选择属性。
- 熵：
  `H(Y) = - sum_y p(y) log2 p(y)`
- 条件熵：
  `H(Y|X)=sum_x p(x) H(Y|X=x)`
- 信息增益：
  `IG(Y, X)=H(Y)-H(Y|X)`
- 选择信息增益最大的属性作为划分属性。

### C4.5 与 CART

- C4.5：用增益率缓解信息增益偏向多值属性的问题。
- CART：二叉树；分类常用 Gini 指数。
- Gini：
  `Gini(D)=1-sum_k p_k^2`
- 连续属性：排序候选切分点，计算切分后的指标。
- 剪枝：预剪枝、后剪枝，防止过拟合。

### 常考题型

- 计算某个属性的信息增益。
- 用 ID3 构建小型决策树。
- 解释 C4.5/CART 与 ID3 的区别。

### 90+ 检查

- 熵计算保留足够小数。
- 条件熵要按分支样本数加权。
- 画树时每个叶子类别要由该子集多数类或纯类决定。

## 10. 聚类：K-means 与 DBSCAN

参考：

- `人工智能第十一讲 正式版.pptx`
- `机器学习-深度学习理论课作业.docx`

### K-means

- 输入：K、初始中心、距离度量。
- 流程：
  1. 根据距离把每个点分到最近中心。
  2. 对每个簇重新计算中心。
  3. 迭代直到中心/分配不再变化。
- 作业要求：给 8 个点、K=2、初始中心、曼哈顿距离，算一次迭代。
- SSE：簇内平方误差和，衡量紧密程度。
- 肘部法则：画 K 与 SSE 曲线，拐点作为候选 K。
- K-means++ / K-means||：改进初始中心选择。

### DBSCAN

- 基于密度的聚类。
- 参数：`eps` 与 `MinPts`。
- 点类型：核心点、边界点、噪声点。
- 优点：可发现非球形簇，能处理噪声。
- 缺点：密度差异大、高维稀疏数据时表现可能不好。

### 90+ 检查

- K-means 一次迭代要写出每个点属于哪个簇。
- 区分“距离度量”和“中心更新”。
- DBSCAN 必须会解释核心点、边界点、噪声点。

- `21年人工智能B卷.pdf`

### 遗传算法 GA

- GA 是基于自然选择和遗传机制的随机搜索算法。
- 基本映射：
  - 个体 = 解。
  - 染色体 = 解编码。
  - 基因 = 编码分量。
  - 适应度 = 评价函数值。
  - 群体 = 候选解集合。
- 基本流程：初始化 -> 适应度计算 -> 选择 -> 交叉 -> 变异 -> 新种群 -> 终止。
- 编码：
  - 二进制编码。
  - Gray 编码。
  - 实数编码。
  - TSP 常用排列编码/随机键编码。
- 选择：
  - 轮盘赌。
  - 排序选择。
  - 锦标赛选择。
  - 精英保留。
- 交叉：
  - 普通：一点、二点。
  - TSP：PMX、OX、CX、位置/顺序/子路径交换，避免非法排列。
- 变异：
  - 位点变异。
  - 逆转、插入、互换、移动。

### 模拟退火 SA

- 高温时以较大概率接受劣解，低温时趋于局部搜索。
- 核心：劣向转移帮助跳出局部极小。
- 三函数两准则：
  - 状态产生函数。
  - 状态接受函数。
  - 温度更新函数。
  - 内循环终止准则。
  - 外循环终止准则。
- 接受函数：`min[1, exp(-DeltaC/t)]`。
- 背包：0-1 编码，翻位产生邻居。
- TSP：排列编码，交换城市或翻转片段产生邻居。

### 90+ 检查

- 对 TSP 能写完整 GA：编码、初始种群、适应度、选择、交叉、变异、参数、终止。
- 对背包能写完整 SA：状态、目标函数、可行性处理、邻域、接受概率、降温、终止。

## 12. 前馈神经网络、BP 与 MLP

参考：

- `第3章 (感知器）.ppt`
- `第3章 (BP算法).ppt`
- `第三次理论作业.pdf`
- `机器学习-深度学习理论课作业.docx`
- `21年人工智能B卷.pdf`

### 单层感知器

- 本质是 M-P 神经元模型。
- 净输入为加权和，输出常用符号函数。
- 二维输入的边界是直线；三维是平面；n 维是超平面。
- 可实现与、或。
- 不能实现 XOR，因为 XOR 线性不可分。

### 感知器学习规则

`Wj(t+1)=Wj(t)+eta[djp-ojp(t)]Xp`

- 有导师学习。
- 若实际输出等于期望输出，不更新。
- 学习率太大不稳定，太小收敛慢。

### 多层感知器

- 加入隐层可解决线性不可分问题。
- 非线性连续激活可形成复杂非线性边界。
- 难点：隐层没有直接期望输出。

### BP

- 适用于多层前馈网络。
- 常用 Sigmoid，损失常用 MSE。
- 思想：误差反向传播 + 梯度下降。
- 输出层误差信号由输出误差直接得到。
- 隐层误差信号由后一层误差信号反传得到。
- 权值更新统一形式：学习率 × 本层误差信号 × 本层输入。

### 90+ 检查

- 会手算一轮 MLP 前向传播。
- 会用链式法则求某个权重的偏导。
- 会按学习率更新权重和偏置。
- 2021 B 卷 BP 题是“求某个参数偏导”，第三次作业是“完整更新所有权重和偏置”。

## 13. CNN、RNN/LSTM 与深度学习概念题

参考：

- `机器学习-深度学习理论课作业.docx`
- `机器学习-深度学习理论课作业答案(1).docx`
- `21年人工智能B卷.pdf`
- `人工智能 第十讲 正式版机器学习导论.pptx`

### CNN

- 卷积基本原理：卷积核在输入特征图上滑动，对局部窗口做加权求和。
- 与全连接相比：
  - 局部连接。
  - 权值共享。
  - 参数更少。
  - 更适合图像空间结构。
- 输出尺寸：
  `K = floor((W - F + 2P) / S) + 1`
- 输出通道数 = 卷积核个数。
- 参数量：
  `F * F * C_in * C_out + C_out`
- 池化：降低空间尺寸，减少计算和过拟合。
- 1x1 卷积：
  - 通道混合与特征重组。
  - 调整通道数，降维/升维。
  - 降低后续大卷积的计算量。
  - 配合激活函数增加非线性。

### RNN/LSTM

- 普通 RNN 长序列反传时连续相乘，容易梯度消失/爆炸。
- LSTM 通过 Cell State 和门控机制缓解梯度消失。
- 三个门：遗忘门、输入门、输出门。
- Cell State 提供较稳定的信息传递路径，保留长期依赖。

### 90+ 检查

- 能手算小矩阵卷积。
- 能逐层算 CNN 输出维度，尤其卷积后接池化。
- 能算卷积层参数量。
- 能用 3-5 句话解释 LSTM 为什么缓解梯度消失。

## 14. Word Embedding、Seq2Seq、Attention、Transformer 与大模型

参考：

- `1.2 大模型技术基础.pdf`
- `LLMBook(1).pdf`

### 词表示与语言模型

- 统计语言模型：n-gram，基于马尔可夫假设。
- 神经语言模型：用向量表示词。
- Word2Vec：
  - CBOW：上下文预测中心词。
  - Skip-gram：中心词预测上下文。
- GloVe：结合全局共现统计学习词向量。
- 预训练语言模型：
  - 自回归：GPT 类。
  - 自编码：BERT 类。

### Seq2Seq 与 Attention

- Seq2Seq：Encoder-Decoder 架构。
- RNN 编码长序列时，固定长度瓶颈导致信息损失。
- Attention：让解码时能关注输入序列的不同位置。

### Transformer

- 核心：Self-Attention。
- Q/K/V：
  - Query：当前 token 要找什么。
  - Key：每个 token 提供什么索引。
  - Value：实际被聚合的信息。
- Scaled Dot-Product Attention：
  `Attention(Q,K,V)=softmax(QK^T/sqrt(d_k))V`
- Multi-Head Attention：多个注意力头并行捕捉不同关系。
- 位置编码：注入序列顺序信息；也有相对位置编码、RoPE 等扩展。
- 残差连接：帮助信息和梯度传播，缓解深层网络退化。
- Layer Normalization：稳定每层输入分布，使训练更稳定。

### 大模型技术

- 大语言模型：超大规模参数的预训练语言模型，主流为 Transformer 解码器架构。
- 训练：通常使用下一个词预测。
- 后训练：指令微调、偏好对齐、RLHF/DPO。
- 能力来源：规模扩展、数据扩展、算力扩展、上下文学习。
- 推理链路：自然语言 -> Token -> 嵌入/位置编码 -> Transformer 层 -> 下一个 Token 分布 -> 采样/解码 -> 流式输出。

### 90+ 检查

- 能解释自注意力为什么适合并行建模长距离依赖。
- 能说明 Transformer 中残差连接和 LayerNorm 的作用。
- 能把“AI 回答一个问题发生了什么”按 Token、嵌入、Transformer、解码、流式输出讲清。

## 15. 强化学习与智能体

参考：

- `强化学习入门3小时张伟楠.pdf`
- `理论第18讲 智能体(1).pptx`
- `8.1 规划与智能体.pdf`

### 强化学习形式化

- 智能体 Agent 与环境 Environment 交互。
- 每一步：观察状态、选择动作、得到奖励、转移到新状态。
- 目标：最大化长期累计奖励/期望回报。
- MDP 五元组：
  `(S, A, P, gamma, R)`
  - S：状态集合。
  - A：动作集合。
  - P：状态转移概率。
  - gamma：折扣因子。
  - R：奖励函数。
- 回报：
  `G_t = R_{t+1} + gamma R_{t+2} + gamma^2 R_{t+3} + ...`

### 价值函数与 Bellman

- 状态价值：`V^pi(s)`。
- 动作价值：`Q^pi(s,a)`。
- Bellman 期望方程：当前奖励 + 折扣后的后继价值期望。
- Bellman 最优方程：对动作取最大。
- 动态规划：
  - 价值迭代。
  - 策略迭代。

### SARSA 与 Q-learning

- SARSA：on-policy，用实际下一动作更新：
  `Q(s,a) <- Q(s,a) + alpha [r + gamma Q(s',a') - Q(s,a)]`
- Q-learning：off-policy，用下一状态最大动作值更新：
  `Q(s,a) <- Q(s,a) + alpha [r + gamma max_a' Q(s',a') - Q(s,a)]`
- 区别：
  - SARSA 学当前行为策略，比较保守。
  - Q-learning 学贪心最优策略，探索行为与学习目标可不同。

### 智能体 Agent

- 智能体：能感知环境、决策并执行动作的实体。
- 现代 AI Agent 组件：
  - 感知。
  - 规划。
  - 工具调用。
  - 记忆。
  - 反思。
  - 多智能体协作。
- ReAct：推理与行动交替，根据反馈调整。
- 单智能体 vs 多智能体：多智能体通过分工协作解决复杂任务。

### 90+ 检查

- 会给定轨迹和 gamma 算回报。
- 会根据 MDP 图求某个状态的 V 值。
- 会写 Q-learning/SARSA 更新公式并比较。
- 能用“状态、动作、转移、奖励、折扣、策略”形式化一个单智能体问题。
